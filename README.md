# Visual Routines

A visual routine builder designed to help children with executive function challenges follow daily routines independently. Perfect for kids with autism, ADHD, or anyone who benefits from visual schedules.

## Why Visual Routines?

Executive functions—planning, focusing, remembering instructions, and managing tasks—can be challenging for many children. Visual routines provide:

- **Clear, predictable guidance** through step-by-step picture schedules
- **Reduced cognitive load** by making abstract concepts concrete
- **Independence** by letting children follow routines without constant reminders
- **Confidence** through successful task completion

## Features

- 🎨 **Visual Activity Cards** - Kid-friendly illustrations for each activity
- 📋 **Custom Routines** - Build personalized morning, evening, or any routine
- 🔄 **Daily Auto-Reset** - Recurring routines reset progress automatically each day
- 🖨️ **Print as PDF** - Export beautiful printable routine sheets
- 📱 **Works Offline** - No internet required after initial load
- 🌍 **Multi-language** - Available in English, Spanish, French, Norwegian, and Macedonian

## Getting Started

1. **Create a routine** - Name it and add activities from the library
2. **Arrange activities** - Drag and drop to set the order
3. **Use it daily** - Check off activities as your child completes them
4. **Print it** - Export as a PDF to hang on the wall or fridge
